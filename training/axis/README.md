# UP 视频轴提取

把 B 站攻略视频里的操作提取成机器可执行的轴：**视频回答"该在什么时候做什么"，
自己的录像回答"画面现在处于什么状态"**——不需要自己会打这条轴。

## 工作流

```text
① 拿到源视频（本地 mp4，优先 1080p60 投稿；30fps 源单帧量化就有 33ms）
   ↓
② 逐帧标注         py -3.12 training/axis/annotate_video.py --video up.mp4
   标"动作在画面上出现"的帧 → up.axis_timeline.json
   ↓
③ 编译             py -3.12 training/axis/compile_axis.py --timeline up.axis_timeline.json
   ├─ RawInputTimeline 宏源码（*_key/*_mouse，粘贴进忌莫守式轴文件）
   └─ 状态机轴节点草表（按站场分组 + 画面实测 gap，整理进秧千穗式轴）
   ↓
④ 输入缓冲校准
   视频标注的是动作"出来"的时刻，真实按键更早一个输入缓冲窗口。
   先用 --lead-ms 0 实机试跑；再用 pydirect_transport_probe 实测
   "按下 → 动作出现"的延迟，把测得值填回 --lead-ms 重编。
   ↓
⑤ 对齐验收
   录下自己机器执行的画面，与 UP 视频逐帧对比每个节点的时刻误差；
   目标先定 ±2 帧（60fps 下约 ±33ms）。
```

## 标注器按键

| 键 | 含义 |
| --- | --- |
| `, / .` | 上一帧 / 下一帧 |
| `J / L` | -10 / +10 帧 |
| `P` | 播放 / 暂停 |
| `A` | 普攻（左键） |
| `V` | 下落 A |
| `E / Q / R / F / W` | 对应技能键 |
| `Z` | 重击（长按左键） |
| `I` | 变奏入场（对齐标记，不产生输入） |
| `1 / 2 / 3` | 切人，同时更新"当前站场" |
| `X` | 撤销最后一个事件 |
| `S / Q` | 保存 / 保存并退出 |

标注器会记住每个事件发生时的站场槽位；再次打开同一 JSON 可继续标注。

## 编译选项

- `--lead-ms N`：全局输入缓冲提前量（见工作流④）。
- `--hold z=550,w=180`：覆盖某个动作的默认按住时长。
- 编译告警（按住被截短、同帧事件、首事件钳位）逐条人工复查后再上机。

## 已知限制

- 一次只支持一个按住中的输入（不支持"按住 W 同时按 E"的和弦）；
  遇到会给截短告警。
- 带按键显示浮层的视频目前仍靠人工对照浮层标注；浮层自动识别是后续方向。
- 视频请自行下载到本地文件；本工具不涉及任何平台下载与分发。
  提取的轴时序数据仅供个人使用，发布衍生内容请注明原作者。
